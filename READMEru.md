# Pax Historia — Мир 1910

Русскоязычная адаптация Open Historia с альтернативно-исторической стартовой
кампанией **1 января 1910 года**. Игрок управляет государством, отдаёт приказы,
а симуляция разворачивает последствия в событиях, дипломатии и на карте.

Проект сохраняет движок и карту Open Historia и добавляет кампанию 1910 года,
локализацию и изменения игровой симуляции. Лицензия проекта — **AGPL-3.0-or-later**,
см. [`LICENSE`](LICENSE). Исходные картографические данные и атрибуция указаны
в `server/seed/1910/source/`.

## Возможности

- политическая карта с регионами, суверенитетом, фактическим контролем и спорами;
- события, дипломатия, войны и перемотка времени с сохранением состояния мира;
- приказы игрока с ожидаемым структурированным результатом, а не только текстом события;
- армии, перемещение войск, проекты, разведка и статистика государств;
- встроенный редактор сценариев и карт;
- русскоязычный интерфейс и русские инструкции дипломатии и симуляции;
- локальный сервер для одиночной игры.

## Запуск через Docker

Нужны Git и Docker Desktop с поддержкой Docker Compose:

```powershell
git clone <адрес-вашего-форка>
cd pax
docker compose up -d --build
```

После старта откройте <http://127.0.0.1:8080/>.

Остановить контейнер:

```powershell
docker compose down
```

Данные игры хранятся в подключённом Docker volume, поэтому пересборка контейнера
не должна сбрасывать сохранения.

## Локальная разработка

Нужен Node.js 22 LTS (минимум 20.19 / 22.12):

```bash
npm install
npm run seed:1910
npm run build
npm test
node server/server.js
```

Откройте адрес, который сервер напечатает при запуске. Основной `npm test`
запускает серверные и клиентские тесты; `npm run build` проверяет production-сборку.

## ИИ-провайдер

Для ИИ-функций нужен совместимый API-провайдер и собственный ключ. Ключ
настраивается в интерфейсе игры. Не добавляйте его в репозиторий, README,
логи или сценарии. При локальной проверке не требуется отправлять запрос,
если задача касается только карты, интерфейса или чистых функций.

## Игровая модель

Приказы игрока рассматриваются как директивы, а не как бросок вероятности.
Симуляция должна фиксировать их в поддерживаемых структурированных операциях:

- военная оккупация меняет контролёра, сохраняя суверена;
- договорная уступка и объединение меняют суверенитет;
- основание нового государства при объединении должно сопровождаться
  передачей ему регионов государств-участников;
- неоднозначную географию нельзя подменять случайным регионом.

Другие государства могут реагировать, торговаться и создавать последствия,
но текст события сам по себе не меняет карту: для этого нужны операции мира.

## Основные файлы

- `scripts/seed-world-1910.mjs` — воспроизводимая подготовка кампании 1910 года;
- `server/seed/1910/` — снимок исходного сценария, карта и источники данных;
- `src/Game/AI/gameplay.js` — сборка симуляции, проверка и применение результатов;
- `src/Game/AI/orderText.js` — нормализация формулировок приказов;
- `src/Game/AI/unionTerritory.js` — перенос регионов при образовании союза/государства;
- `src/Game/Map/Nations.jsx` — карта, отрисовка территории и переходы цвета.

Полный перечень изменений и причины собраны в [`CHANGES_RU.md`](CHANGES_RU.md).
